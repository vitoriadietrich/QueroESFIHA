# QueroESFIHA

Sistema de pedidos desenvolvido em **Java** como parte dos exercícios de programação e lógica.

O projeto simula o funcionamento de uma loja de esfihas, permitindo visualizar o cardápio, selecionar combos e bebidas, controlar estoque, calcular o valor do pedido, aplicar desconto VIP e escolher a forma de pagamento.

## Funcionalidades

* Cadastro do nome do cliente
* Exibição do cardápio
* Seleção de combos
* Seleção de bebidas
* Controle de estoque
* Cálculo do valor total do pedido
* Desconto de 10% para clientes VIP conforme a regra do sistema
* Escolha da forma de pagamento
* Confirmação do pedido
* Opção de sair do sistema

## Objetivo

O objetivo deste exercício é praticar os fundamentos da programação em Java através da criação de um sistema simples e interativo, simulando uma situação próxima de um sistema real de pedidos.
